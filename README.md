# agent-blast-radius

Harness, trial records and analysis for the paper **"When an AI agent makes a mistake in a database, what decides the
damage?"** by Abdullah Kaya, Mehmet Cevheri Bozoğlan and Yusuf Gündoğdu (LibreDB Studio project).

- Paper: arXiv (link added at announcement)
- Archive with all trial records: https://doi.org/10.5281/zenodo.24445015
- Preregistration and amendment: https://osf.io/ms7ef (also in `protocol/`)

## What is here

| Path | Contents |
|---|---|
| `src/`, `engines/` | Engine contract and one module per engine: start, seed, snapshot, reset, credentials, recovery drill |
| `layer-a/` | Model-free layer: the frozen mistake library applied by script, plus recovery drills |
| `layer-b/` | Live-agent layer: the minimal tool-calling agent, tasks, scorer and replay drill |
| `analysis/` | Scripts that produce every number in the paper from the trial records |
| `tests/` | One smoke test per engine; they inject known damage that the state diff must detect (`scripts/smoke-all.sh` runs all) |
| `scripts/` | Run, model-serving, image-pull and release scripts |
| `manifest/` | Pinned engine images and model files |
| `protocol/` | Preregistration, amendment and the deviation log |
| `report/appendix.md` | Appendix A of the paper, generated by `report/build_appendix.py` |

`ARCHITECTURE.md` describes the layers, the engine contract and the isolation rules. The trial records are not in
this repository because of their size; they are in the Zenodo archive above.
